# 计算机组成原理 · 重难点

## 重点（必须会算）
- 补码加减运算与溢出判断（双符号位法）
- IEEE 754 浮点数的表示与加减运算步骤
- Cache 三种映射的**地址划分计算**（标记/组号/块内地址位数）——近年 408 高频计算题
- 指令流水线的周期、吞吐率、存在相关时的实际耗时

## 难点
- 一条指令在 CPU 数据通路上的完整执行流程（看懂即可，不必设计）
- 浮点数规格化与阶码下/上溢
- 组相联 Cache 的命中分析与替换

## 易错点
- Cache 容量/块大小/组数之间的位数计算
- 流水线「吞吐率」与「实际加速比」的区别
- 补码乘法/除法的硬件思路（理解即可）
