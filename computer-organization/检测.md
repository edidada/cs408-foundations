# 计算机组成原理 · 如何检测掌握情况

## 硬性自测（不看资料完成）
- [ ] 能算补码加减并判断溢出
- [ ] 能按 IEEE 754 写出一个十进制数的机器表示
- [ ] 能算 Cache 地址划分（直接映射 / 组相联），给出标记/组号/块内地址位数
- [ ] 能算指令流水线在存在相关时的总时钟数、吞吐率

## 框架自测
- 合上书，画出「组成原理」知识框架图（数据表示到存储到指令到CPU到总线I/O）
- 给同事讲清：为什么按列访问大数组更慢（局部性 + Cache）、一条 a = b + c 指令在 CPU 里走了哪几步

## 跨科自测
- 能说出「Cache」与「操作系统页表/TLB」在思想上的相似性（都是用小块缓存加速大空间访问）
- 若以上都能做到，本门功课底已补上；偏题怪题可放过。
