# 计算机组成原理 · 实践规划（不涉及代码）

本门没有工程经验可借用，实践目标是**建立物理直觉 + 把抽象概念对应到真实机器行为**。

## 1. 动手装机（可选，约 800–1000 元）
- 买二手服务器配件（E5 处理器 + 华南主板）装一台机器
- 在装机过程中理解 CPU、内存、主板、总线、电源的物理关系——比看书直观得多

## 2. 观察程序运行时的硬件行为（不花钱）
- 写一个大数组遍历程序（超过 Cache 容量），分别按行、按列访问，用 time / perf 对比耗时，体会局部性与 Cache 命中
- 打开任务管理器，观察程序运行时内存占用变化、CPU 占用波动，把现象和书上的「存储层次 / 指令执行」对应起来
- 用 Wireshark 抓一次网络包，感受「数据如何在总线上流动」（与网络阶段衔接）

## 3. 计算题专练
- 每学完一个计算点（补码、IEEE754、Cache 地址、流水线），立即做 10 道同类选择题
- 把计算过程写在纸上，不依赖计算器，训练考场的手算速度
