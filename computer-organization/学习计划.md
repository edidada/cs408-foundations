# 计算机组成原理 · 学习计划

- 周期：6–8 周（每周 10–12 小时）—— **最长、最该慢啃的主战场**
- 定位：你没有任何工程经验可借用，必须从零补
- 策略：把数据表示、存储系统、指令系统三大模块拆开逐个击破，配合动手/观察建立物理直觉

## 周安排建议

- 第 1–2 周：数据的表示与运算（进制、补码、IEEE 754、溢出）
- 第 3–4 周：存储系统（Cache 映射、地址划分、主存与虚拟存储）
- 第 5–6 周：指令系统与 CPU（指令格式、寻址、数据通路、流水线）
- 第 7–8 周：总线与 I/O + 综合计算题专练（Cache 地址、流水线周期）
