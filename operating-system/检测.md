# 操作系统 · 如何检测掌握情况

## 硬性自测（不看资料完成）
- [ ] 能默写生产者-消费者、读者-写者 PV 伪代码（含信号量初值）
- [ ] 能讲清「逻辑地址 → 页表 → TLB → 缺页中断 → 物理地址」的完整流程
- [ ] 能手算给定访问串下的页面置换与缺页次数（LRU/FIFO/Clock）
- [ ] 能说出 inode 中存了哪些字段、三种文件分配方式的优劣

## 框架自测
- 合上书，画出「操作系统」知识框架图（进程→同步→内存→文件→I/O）
- 给同事讲清：为什么多线程程序要用信号量、缺页时操作系统到底做了什么

## 跨科自测
- 能把「Cache 命中/失效」与「页表命中 TLB / 缺页」类比讲解
- 若以上都能做到，本门功课底已补上；偏题怪题可放过。
