# 操作系统 · 重难点

## 重点（必须练到能默写）
- PV 操作手写生产者-消费者、读者-写者伪代码——408 直接考
- 页面置换算法的**手算**（给定访问串，逐步推置换过程与缺页次数）

## 难点
- 页表 / TLB / 缺页中断的**完整流程**（地址变换全过程）
- 虚拟内存与组成原理 Cache 的跨科目综合（近年 408 大题趋势）
- 读者-写者中「写者优先 / 读者优先」的差别实现

## 易错点
- 信号量初值的设定（empty/full/mutex 各代表什么）
- LRU 与 FIFO 的 Belady 异常区别
- inode 直接/间接块指针能支持的文大小计算
