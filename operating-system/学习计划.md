# 操作系统 · 学习计划

- 周期：4–5 周（每周 10–12 小时）
- 定位：用你的工程经验反推原理，但警惕「经验替代原理」
- 策略：进程管理你上手快；把省下的时间压在 PV 操作默写、虚拟内存完整流程、inode 细节上

## 周安排建议

- 第 1 周：进程与线程、CPU 调度算法、进程同步（临界区、信号量）
- 第 2 周：PV 操作专练（生产者-消费者、读者-写者，练到能默写）
- 第 3 周：内存管理（分页/分段、页表、TLB、虚拟内存、缺页、置换算法）
- 第 4 周：文件系统（inode、分配方式）+ I/O 管理
- 第 5 周：跨科目综合（存储系统 + 虚拟内存）+ 真题
