# 操作系统 · 实践规划（不涉及代码）

本门你最有工程经验，实践重点是**把「用过」变成「讲得清原理」**，并做抽象与实现的对照。

## 1. PV 操作：抽象 vs 实现对照
- 用 pthread + 信号量实现一个生产者-消费者队列（动手时写代码，本文件不列代码）
- 把每一行 P/V 调用与 408 的 PV 伪代码逐行对应，确认「抽象」和「实现」说的是同一件事

## 2. 虚拟内存：观察缺页与 swap
- 写程序分配超过物理内存的大数组并随机/跨页访问
- 用 /proc/vmstat 观察 pgfault 前后差值（缺页次数），用 vmstat 1 观察 si/so（swap in/out）
- 把观察到的现象与书上的「缺页中断 → 调入页框 → 可能换出」流程对应

## 3. 文件系统：看清 inode
- 在 Linux 下用命令查看文件 inode 信息（权限、大小、时间戳、块指针）
- 对照书上 inode 结构图，确认「inode 里到底存了什么」
- 结合组成原理的 Cache，思考「存储系统 + 虚拟内存」的综合题怎么出
