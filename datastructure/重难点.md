# 数据结构 · 重难点

## 重点（必须能手写/手推）
- 单链表反转（迭代与递归）
- 二叉树三种非递归遍历，尤其是**后序非递归**
- 图的**非递归 DFS / BFS** 完整写出
- 快速排序的 partition 过程与边界处理

## 难点（平时用内置结构永远看不到，必须纸推）
- B 树插入/删除的**分裂与合并**全过程
- AVL 树 LL / RR / LR / RL 四种旋转及平衡因子更新
- 哈希表冲突处理后**查找长度（ASL）的计算**（线性探测、链地址法）

## 易错点
- 非递归后序遍历的栈状态变化
- 快排 partition 的循环不变量与越界
- B 树阶（m 阶）与关键字上限的关系（ceil(m/2)-1 ~ m-1）
