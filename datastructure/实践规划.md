# 数据结构 · 实践规划（不涉及代码）

本阶段实践的核心是「**手写**」与「**手推**」，不依赖任何语言内置容器。

## 1. 手写核心算法（每天 1–2 个）
- 用 C 或 C++ 写，**不调用 STL / 语言内置容器**
- 清单：链表反转、二叉树前/中/后序非递归遍历、图的 DFS/BFS、快排 partition
- 目标：能在白纸上十分钟之内无错写完

## 2. 纸推结构变化
- B 树插入/删除的分裂合并：自己出题，逐步画图
- AVL 旋转：给定插入序列，逐步画旋转过程
- 哈希冲突：给定散列函数与冲突处理方法，手算 ASL

## 3. 真题检验
- 用王道近 10 年真题的算法大题，掐表手写完整代码
- 错题回到对应知识点重推，不背答案

## 4. 代码实验（外部仓库，submodule）
- external/408-ds-os-code：收录 408 数据结构与操作系统的代码实现（含真题），可参考/编译其中的链表、栈队列、树、图、排序等实现，对照你手写的版本查漏。
- external/csapp-labs 中的 data lab（01-data-lab）也适合练位级与浮点表示（对应组成原理数据表示）。
