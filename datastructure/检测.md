# 数据结构 · 如何检测掌握情况

## 硬性自测（不看资料完成）
- [ ] 能手写链表反转、二叉树三种非递归遍历、图 DFS/BFS、快排 partition
- [ ] 能在纸上完整推演一次 B 树插入分裂、一次删除合并
- [ ] 能画出 AVL 在给定插入序列下的旋转过程
- [ ] 能手算给定哈希表的 ASL（成功/不成功）

## 框架自测
- 合上书，画出「数据结构」知识框架图（线性表→栈队列→树→图→查找→排序）
- 给一个同样有开发经验但没系统学过的人，讲清：为什么快排平均 O(n log n)、B+ 树为什么适合数据库索引、哈希冲突怎么影响性能

## 真题自测
- 做 2–3 套真题算法题，能独立写出可运行思路的伪代码/代码
- 若以上都能做到，本门功课底已补上；偏题怪题可放过。
