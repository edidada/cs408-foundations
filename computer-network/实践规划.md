# 计算机网络 · 实践规划（不涉及代码）

本门以「观察 + 计算 + 记忆」为主，实践目标是把抽象协议和真实流量对应起来。

## 1. Wireshark 抓完整 TCP 连接
- 抓一次访问 HTTP 网站的全过程
- 对照报文标注每个包对应的状态：SYN / SYN+ACK / ACK（三次握手）→ 数据传输 → FIN / ACK（四次挥手）
- 把抓到的包和书上的 TCP 状态机逐一对上

## 2. 计算题专练
- CIDR 子网划分：给定 IP 与掩码，求网络号/主机范围/可用地址数
- 路由聚合：把若干连续子网合成一条聚合路由
- 拥塞控制：给定初始窗口与 ssthresh，逐步推每一轮的 cwnd 值

## 3. 协议细节记忆表
- 整理一张对比表：CSMA/CD 退避、DNS 递归/迭代、HTTP 状态码、各层设备（集线器/交换机/路由器）
- 用 ping / traceroute 观察网络层行为（TTL、路径），和书上概念对应

## 4. 真题
- 做历年网络选择题，错题归类到「状态机 / 计算 / 协议细节」三类中反复练

## 5. 说明（网络暂无代码 submodule）
- 本阶段以 Wireshark + 计算为主，暂不挂外部代码仓库；抓包文件（.pcapng）与笔记放在本目录即可。
- 若后续想加网络编程实验（socket / 简易 TCP 服务器），可再引入一个 repo 作为 submodule。
