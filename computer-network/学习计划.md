# 计算机网络 · 学习计划

- 周期：3–4 周（每周 10–12 小时）
- 定位：分值最低（25 分），但选择题细节极多、计算量在上升，不要轻视
- 策略：以「记忆 + 计算」为主，抓 TCP 状态机、拥塞控制计算、子网划分计算三块硬骨头

## 周安排建议

- 第 1 周：物理层 + 数据链路层（CSMA/CD、CRC、MAC、交换机）
- 第 2 周：网络层（IP、CIDR、子网划分、路由聚合、ARP/ICMP、路由协议）
- 第 3 周：传输层（UDP、TCP 三次握手/四次挥手、可靠传输、拥塞控制）
- 第 4 周：应用层（DNS、HTTP/HTTPS、FTP、邮件）+ 综合计算题专练
