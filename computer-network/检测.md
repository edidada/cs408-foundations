# 计算机网络 · 如何检测掌握情况

- [ ] 能画出 TCP 三次握手 / 四次挥手的状态机与每个包的 flag

- 给同事讲清：访问一个网址时，从 DNS 解析到 TCP 建连到 HTTP 请求，每层发生了什么
