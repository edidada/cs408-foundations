# 计算机网络 · 重难点

## 重点（必须会画会算）
- TCP 三次握手 / 四次挥手的**状态机与报文标志**（SYN/FIN/ACK）
- 拥塞控制的**窗口变化计算**（慢启动阈值 ssthresh、指数/线性增长、乘法减小）
- CIDR 子网划分与**路由聚合**的计算题（选择题必练）

## 难点
- 为什么需要三次握手（防止失效连接请求）、TIME_WAIT 的意义
- 快恢复与拥塞避免的衔接、拥塞窗口与接收窗口的区别
- 路由聚合时的地址边界与最长前缀匹配

## 易错点
- CSMA/CD 的退避算法（第 k 次冲突退避 [0, 2^k-1]）
- DNS 递归与迭代的区分（客户端到本地 DNS 是递归，本地到根/权威是迭代）
- HTTP 常见状态码（2xx/3xx/4xx/5xx）含义
